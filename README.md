# 账号救援模板

这是一个简单的网页，用于展示账号救援邮件的回复模板。

## 在线访问

你可以通过 **GitHub Pages** 在线访问该页面。  
部署完成后，访问地址格式如下：

```
https://github.com/K-Blaaaack/K-Blaaaack.github.io/tree/BlueArchive-Account-Recovery
```

## 使用方法

1. 下载或克隆本仓库。
2. 将 `index.html` 保存在仓库根目录。
3. 在 GitHub 仓库设置中，找到 **Pages**，将分支设置为 `main`（或 `gh-pages`），并选择根目录。
4. 保存后等待几分钟，即可通过 GitHub Pages 访问。

## 文件说明

- `index.html` ：主网页文件，包含账号救援模板。

## 效果截图

页面包含：
- 标题 **账号救援模板**
- 提示信息：提交了申诉之后，他发回个邮件告诉要补充信息，就用这个模板去回复
- 白色卡片区域展示完整的模板文本

---

如果要修改模板内容，只需直接编辑 `index.html` 中的 `<pre> ... </pre>` 部分即可。
